# Test fixtures

Generated by `scripts/gen-fixtures.ts` (PLAN.md task 0.3). Output is deterministic: every run produces byte-identical files, so a fixture name always means the same content.

```bash
pnpm fixtures                 # all fixtures (~300 MB, ~20 s)
pnpm fixtures --small         # only the small, committed ones
pnpm fixtures bad deep.json   # by name (extension optional)
```

| File | Size | What it tests | Committed |
|---|---|---|---|
| `deep.json` | 7 KB | 500 levels of nesting (alternating objects and arrays) | yes |
| `wide.json` | 16 MB | array of 200k small objects | no |
| `big-50mb.json` | 50 MB | array of realistic API records (`_id` as `{"$oid": …}`, nested address, arrays) | no |
| `big-200mb.json` | 200 MB | same, 200 MB | no |
| `bigint.json` | 4 KB | numbers JSON.parse can't keep: `12345678901234567890`, int64/uint64 limits, `1.10`, `1e400`, `-0.0` | yes |
| `unicode.json` | 2 KB | emoji (incl. ZWJ, flags), RTL, combining marks, `\u0000`, lone surrogate, odd keys (`""`, `a.b`, `quote"key`) | yes |
| `bad.json` | <1 KB | missing comma at **line 18, column 5** | yes |
| `data.jsonl` | 19 MB | 100k JSON lines; lines **1234** (truncated), **50000** (trailing comma), **99999** (not JSON) are malformed | no |
| `embeddings.json` | 9 MB | embeddings-API-style response: 1000 unit vectors of 1024 floats, plus a short `bbox` array | no |
| `llm-trace.json` | 4 KB | chat-completions style (`tool_calls`, `tool` messages) and messages style (`tool_use` / `tool_result` blocks), both with `usage` | yes |

The expected error position, malformed JSONL lines and unsafe number literals are exported from `scripts/fixtures/generators.ts` (`BAD_JSON_ERROR`, `JSONL_MALFORMED_LINES`, `BIGINT_LITERALS`), and `tests/fixtures.test.ts` checks them. That test also fails if a committed fixture drifts from the generator; run `pnpm fixtures --small` after changing it.
